# 東京ディズニーシー 3D 再現(個人用)

OSM・国土地理院データから東京ディズニーシーを Blender で組み立てる下書きプロジェクト。
個人の練習用で、公開や配布はしない。

- 枠線モック(平面図 + 3D ワイヤー): `output/disneysea/tds_outline.html`(`export_mock.py` がテンプレートから作る)
- Blender 下書き: `disneysea_draft.py`(箱の建物・地形・園路・ランドマーク)
- 水面: `ds_water.py`(Blender なしで水面モデルを計算)→ `disneysea_water_blender.py`(Blender で描く)

`python ds_water.py` で `plateau_data/disneysea_water.json` を作る。中身は次のとおり。

- **水域 38 か所**: OSM の `natural=water` をもとにしている。メインの港(OSM relation 3531413)はミステリアスアイランドの中を通っていて、ロストリバー → トンネル → カルデラ湖 → トンネル → 港とつながる(トランジットスチーマーラインの経路)。このうち空が見えている**カルデラ湖**だけを航空写真から切り出して残し、岩の下を通る部分は `tunnels` に分けた(地面に穴を開けない)。
- **水位**: 岸の地面の高さ(国土地理院 DEM5A、園路の中央値 5.29 m を 0 とする)から、水域の種類ごとの余裕高を引いて決める。港は 1.0 m、カルデラ湖は 1.3 m、水路は 0.7 m、池は 0.35 m、噴水は 0.25 m。DEM は水面では値が補間されているだけなので、水位そのものは DEM から読まない。カルデラ湖はトンネルでつながっているので、港と同じ水位にしている。
- **水深**: 港 2.5 m、カルデラ湖 3.0 m、水路 1.2 m、池 0.6 m(推定)。
- **岸の種類**: 岸の各区間について、陸側 2.5 m の地点に何があるかで決める。

  | 種類 | 判定 | Blender での形 | 長さ |
  |---|---|---|---|
  | 石積みの護岸 | 下のどれにも当たらない | 垂直の石積み + 笠石 | 4.58 km |
  | 植栽の土手 | 芝・庭・樹林 | 草の斜面 → 泥の斜面 | 1.75 km |
  | 岩場の岸 | scree / bare_rock | でこぼこの岩の斜面 | 1.28 km |
  | 建物が水際に立つ | 建物の敷地 | 濡れた基礎の壁 | 1.25 km |
  | 砂浜 | sand / beach | ゆるい砂の斜面 | 0.36 km |
  | トンネルの口 | トンネル部分 | 石積み | 0.07 km |

- **桟橋** 3 か所(`man_made=pier`): 板張りの床と杭。

Blender 側の実行方法:

```
python ds_water.py
blender -b --python disneysea_water_blender.py -- --cams harbor,caldera --samples 64
```

カメラ: `top aerial harbor caldera american rock lost_river fantasy`。
水は閉じた体積として作っている(屈折 + 吸収 + さざ波のバンプ)。地面はブーリアンで水の形をくり抜く。

### 分かっている限界

- DEM と航空写真はどちらも**ファンタジースプリングス開業(2024 年)より前**のもの。このエリアの水位は推定にしている。
- 地面は平ら(園路 = 0)で、水位は「岸から何 m 下か」で置いている。DEM による絶対的な高さはモック側で使っている。
- 滝・噴水の水の流れ、船、水中の照明はまだ作っていない。
- 余裕高と水深は現地で測ったものではなく、推定値。

## データの出典

- 地図データ: © OpenStreetMap contributors(ODbL)
- 標高: 国土地理院 基盤地図情報 数値標高モデル 5 m メッシュ(DEM5A)
- 航空写真: 国土地理院 シームレス空中写真(カルデラ湖の輪郭を取るのと、岸の確認にだけ使用。テクスチャには使っていない)
