# 宣伝用の動画(絵本の冒険)

モックのオープニングの「飛び出す絵本」を使った、約 50 秒の宣伝用の動画。
モックの操作画面は映さず、絵本を開いて中に入り、紙の切り絵でできた世界を旅する。
アプリとは別物で、このフォルダはリポジトリに置くだけ(Vercel が配信するのは `output/disneysea/` だけなので、公開サイトには出ない)。

- 見かた: ブラウザでその場で描いて再生する(押すと音楽つきで流れる)。リポジトリの直下で `python -m http.server` を動かし、http://localhost:8000/promo/promo.html を開く
- MP4 が要るときだけ `promo/record.py` で書き出す(1920×1080・30fps・音つき。書き出した MP4 はコミットしない)

## 流れ

絵本の見開きと、絵本の中の世界は、どちらも実際のパークの位置関係のまま簡略化したもの(モックのデータ `output/disneysea/mock_data.json` から `promo/world_data.py` が作る `promo/world.json`)。

| 時間 | 場面 | 字幕 |
|---|---|---|
| 0–9 秒 | ろうそくの灯る机に革の本が舞い降り、開く。見開きは両パークの地図(外形・水面・緑地・建物。2 つのパークが左右のページに収まるように回し、方位記号は本当の北を指す)。ページが 3 枚めくれ、切り絵が地図の上の本当の場所に立つ: ランドの中央にお城、シーに火山・港町(メディテレーニアンハーバーの大きな建物)・タワー・オブ・テラー・入口の地球儀 | ある夜、ふしぎな絵本がひらきました。/ ページの中には、夢の王国。 |
| 9–11.5 秒 | 地球儀の切り絵へ飛び込み、白く光る | さあ、絵本の中へ―― |
| 11.5–17 秒 | 絵本の中の世界。紙でできた両パーク(建物はすべて実際の形と高さの紙の箱、エリアごとの色)。シーの入口のアクアスフィアの上から港町へ | 地球儀の広場から、港町へ |
| 17–21 秒 | メディテレーニアンハーバーの水面の上を、ゴンドラとカモメの間を低く飛ぶ | ゴンドラのゆれる港をこえて |
| 21–25 秒 | プロメテウス火山(実際の等高線をなめらかにつないだ山)が噴火する | 火を噴く山を見あげ |
| 25–30 秒 | 高く上がって北西へ。東京ディズニーランドへ飛ぶ(夕暮れになっていく) | 海をこえて、となりの王国へ |
| 30–35 秒 | ワールドバザールの側に降りると、正面でシンデレラ城が紙から立ち上がり、光がはじける | ワールドバザールの先に…… |
| 35–41 秒 | 星空のお城に花火が上がる | お城の空に、光の花がひらく。 |
| 41–46 秒 | 光が明けると、机の上の本の中のお城(同じ構図でつなぐ)。カメラが引き、切り絵がたたまれ、本が閉じる | |
| 45.5–50 秒 | 表紙の上にタイトル「Disney Adventure」、キャッチコピー、URL、出典 | 絵本をひらいて、ふたつのパークを 3D で冒険しよう。 |

簡略化したところ: 細い塔(街灯・マスト・尖塔)は低くして箱にする。アクアスフィアとシンデレラ城は実物より大きく、火山は 1.3 倍の高さ。エリア名は紙のリボンで浮かべる。

絵はすべて `promo/promo.html` の中でコードで描いている(モックの `popbook` と同じ水彩・インク・紙の描き方)。
音楽もオリジナルで、`promo/music.py` が numpy で合成する(オルゴールのワルツ、ハープ、弦のパッド、本・ページ・噴火・花火などの音。ヘ長調・3/4 拍子)。

## 作り直す

```
pip install playwright imageio-ffmpeg numpy scipy shapely
python promo/world_data.py   # 絵本の地図と世界のデータ → promo/world.json(モックのデータを取り直したとき)
python promo/music.py    # 音楽 → promo/music.m4a
python promo/record.py   # MP4 が要るときだけ → promo/promo.mp4(1 コマずつ撮るので、Chromium のソフトウェア描画で 50 分ほど)
python promo/record.py --stills 7,17,38   # 何秒目かの静止画だけ(見た目の確認用)
```

- `promo/promo.html` は時間だけから 1 コマを描く(`PROMO.frameAt(ms)`)。乱数も固定なので、何度作っても同じ絵になる。
- 字幕・タイミング: `promo/promo.html` の `CAPS`(字幕)、`frameAt`(場面の切り替え・白い光)、`world` の `K`(カメラの道すじ。座標はモックと同じ、+x 東・+y 北のメートル)。音の出るタイミングは `promo/music.py` の末尾にまとめてある。場面の時間を変えたら両方そろえる。
- Playwright の Chromium がない端末では `--chromium <実行ファイル>`、cdn.jsdelivr.net に届かない端末では `--three <three.min.js 0.147.0>`、ブラウザがプロキシの証明書を信頼しない端末では `--proxy-fonts`(Web フォントを Python から取る)。
