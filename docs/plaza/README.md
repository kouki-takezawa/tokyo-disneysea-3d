## 4. 写真から読める要点(推定は「推定」と明記)

**キャッスルフォアコートのステージ建物**(`commons_plaza_overview_forecourt_stage.jpg`):
- 2階建て、壁はクリーム〜白、トリムと屋根は濃い緑(ボトルグリーン)
- 中央棟に切妻+時計、左右に低い翼棟(それぞれ小さな切妻)、屋根端に小さなドーム状の飾り塔
- 2階に白い手すり子のバルコニー、1階は アーチ窓
- 屋根の稜線に鉄の装飾クレスティング
- 高さは目視で2階建て+塔飾り分、推定7〜9m程度(推定)

**キャッスルフォアコート(城前広場)**(`commons_castle_gate_front.jpg`):
- 舗装は明るいベージュ〜グレーの石畳/ユニット舗装、GATE手前はやや細かい模様
- GATE左右に白い石造りの欄干(ターンド・バラスター+笠木)、緩やかにカーブして広場に降りる
- フラッグポール(赤白の小旗)が左右対称に並ぶ
- 城壁下層はベージュ〜グレーの石積み、上層は白、屋根は青灰色の円錐、金の飾り

**クリスタルパレス・レストラン外観**(`commons_crystal_palace_restaurant_1.jpg` / `_2.jpg`):
- 壁はクリーム〜淡い黄色
- 屋根は濃いボトルグリーンの鉄骨+ガラスのアーチ(温室建築、切妻を連ねた構成)
- 棟に鉄の装飾クレスティング、屋根の頂部に小さな採光塔(ランタン状の小尖塔)が複数
- 1階はほぼ全面ガラス張り、白い方立て
- 規模はプラザパビリオンと同程度(OSM外形約55×55m)の大きな建物 — 実際の高さ・軒の詳細は写真の角度上は読み取りにくく高さは推定2階分+ガラス屋根(推定)

**プラザパビリオン・レストラン外観**: 写真なし。OSM外形(約56×44m)のみ。既存モック内の資料(次フェーズで別途現地写真や地図画像を要確認)。

**プラザの街灯・ベンチ・柵・花壇**:
- ベンチ(`commons_wb_arcade_bench_lamp.jpg`、※WBアーケード内の参考): 濃緑色の木製すのこ座面・背もたれ、鋳鉄の唐草状の脚・肘掛け — ヴィクトリア調パークベンチ。プラザ本体のベンチが同一意匠かは未確認(推定で流用可能とみる)
- 街灯(`commons_entrance_canopy_lamps.jpg`、※入口柱廊の参考): 白い球形ガラスグローブ、黒い鉄の腕木・柱、角柱(白/クリーム)の柱廊に取り付け。プラザの独立ポール灯は未確認、様式のみ参考(推定)
- 柵: `commons_castle_gate_front.jpg` の白い石造欄干(ターンドバラスター)。花壇の柵(barrier=fence、OSM多数)は写真での確認できず、白ペンキの低い鉄柵の可能性(推定、既存の `ds_tdl_plaza_buildings.py` 等の他エリアの柵意匠を参考にできる)
- 花壇(`commons_castle_garden_flowerbed_edge.jpg`、※城西側庭園の参考): 芝生の縁に沿って白い小花(推定インパチェンスなど)のリボン状の縁取り、立ち上がり縁石なし、芝とほぼ同じ高さ。木・トピアリーは同写真に写っているが方針により無視
- 舗装: 航空写真で中心部は放射状の模様(明るいグレー/ベージュの舗装材とみられる。色の細部は解像度不足で推定)、周回路は無地グレー、外周は芝生帯
