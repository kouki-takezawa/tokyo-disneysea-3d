# 草津温泉 湯畑ジオラマ計画(2026-10-10)

ユーザー指示(2026-10-10):「草津温泉街、湯畑周辺のジオラマを作る。個人利用なので店の看板も実名でOK」

## 方針

- **形**: 卓上ジオラマ(切り出した地面の断面+台座)。湯畑を中心に半径 200 m(西の河原通り・光泉寺まで含む。ユーザー決定 2026-10-10)。Three.js の Web ビューア(回して眺める+散歩視点)。Vercel で公開(URL は共有範囲に注意:看板が実名のため、個人利用の範囲で。公開するかはフェーズ6で確認)。
- **作り方**: OSM(建物の外形・道・湯畑)+PLATEAU(あれば標高・建物高さ)で配置、見た目は写真(`images/kusatsu/`)と並べて作り込む。Blender で手続き生成 → glTF 書き出し → ページ。既存の宇都宮ビューア・TDL モックの書き出し手順を流用。
- **看板は実名**(ユーザー許可)。店名・旅館名・商品名は写真で読み取れたものだけを入れる。読めないものは入れない(推測で書かない)。ロゴ・商標は個人利用の範囲。
- **リアル優先**(`feedback_realistic_first`): 湯畑の石縁、木樋、白い湯の花、屋根の勾配、軒先、格子、提灯など、凹凸・奥まった開口まで初版から入れ、写真と並べて確認してから報告。
- **動き**: 湯の流れ(木樋→滝→湯畑)、湯けむり(粒子+半透明)、観光客(少数、歩く)。
- **夜景は作らない**。ライトアップ版は入れない。
- **参考資料のルール**: 自分で撮った写真・ユーザー提供の写真を優先。Street View は目視参考の数枚のみ(テクスチャ化・大量取得は不可)。YouTube Shorts は使わない。動画フレームはテクスチャにせずリポジトリに入れない。
- 他タブの未コミット変更(`src/export_mock.py` など)は勝手にコミット・破棄しない。Blender の同時ヘッドレス起動は他タブと調整してから。

## 対象(湯畑周辺)

| 区分 | 内容 |
|---|---|
| 湯畑 | 石縁の池、木樋(7本)、湯滝、湯の花の白い付着、周囲の柵・石畳、湯けむり |
| 周辺の建物 | 御座之湯、湯畑に面する旅館・土産店・飲食店、足湯、熱の湯方面、光泉寺と石段、バスターミナル方向 |
| 道・地形 | 湯畑を底にした坂、西の河原通りへの道、石段、石畳、電柱・電線、標識 |
| 小物 | 提灯、のれん、看板(実名)、自販機、ベンチ、街灯、足湯のタオル掛け |
| 動き | 湯の流れ、湯けむり、歩行者 |

正確な一覧はフェーズ0で `docs/kusatsu/inventory.md` に作る。

## フェーズとモデル

| フェーズ | 内容 | モデル |
|---|---|---|
| 0 資料と範囲 | 範囲と座標系を決める(湯畑の中心を原点、+X=東)。OSM 取得(建物・道・水)、PLATEAU に草津町(群馬県)があるか確認し、あれば標高と建物高さを取る(`fetch_plateau.py` を参考に新規 `fetch_kusatsu.py`)。無ければ OSM の `height`/`building:levels`+写真で高さを決める。建物の棚卸し(名前・用途・階数・屋根形)を `inventory.md`、写真のフォルダ `images/kusatsu/` を用意し、**ユーザーに写真を依頼**(湯畑を四方から、各建物の正面、看板、湯樋、石段) | Sonnet 5.5 |
| 1 地形と台座 | 標高(なければ坂を写真・OSM の道から推定)、地面、道・石畳・石段、ジオラマの台座(断面)。ビューアの骨組み(回転・ズーム・散歩視点・品質段階)。宇都宮ビューアの構成を流用 | Sonnet 5.5 |
| 2 湯畑 | 石縁、木樋、湯滝、湯の花、柵。写真と並べて確認。ここが見せ場なので最も作り込む | Opus 5.5 |
| 3 建物(箱→屋根→壁面) | 全建物を OSM の外形で押し出し、屋根形(切妻・入母屋・寄棟)と軒、窓・格子・扉・庇。主要建物(御座之湯など)は個別に作り込み | Opus 5.5(量が多ければ範囲を分けて複数会話) |
| 4 看板・小物・電線 | 実名の看板(canvas テクスチャか Blender のテキスト)、提灯、のれん、自販機、街灯、電柱・電線 | Sonnet 5.5 |
| 5 動きと空気 | 湯の流れ、湯けむり、歩行者、雲、空。木・植え込みは写真で確認できた位置だけ(`feedback_plants_confirmed_only`) | Opus 5.5 |
| 6 仕上げと公開 | スマホ向けの軽量化(圧縮、品質段階)、全方向の確認、README と進み具合、Vercel 公開(公開範囲はユーザーに確認) | Sonnet 5.5 |

各フェーズ = 1コミット + push。終わったら下の「進み具合」に `済(commit、日付)` と要点を追記。

## 運用

- 1会話 = 1フェーズ。終わったら「/clear してから『草津計画のフェーズN から』」と案内する。
- モデルはサブエージェントの model 指定で切り替える。メインの会話は段取りと確認・報告だけ。
- 確認は数値(三角形数・描画数・ファイルサイズ)+縮小スクショ1〜2枚と写真の比較。
- 大きいファイルは grep で位置を探して部分だけ読む。

## 決定事項(2026-10-10)

1. 範囲: 半径200 m(湯畑〜西の河原通り〜光泉寺)。
2. 写真: ユーザーは用意できない。**ネットの画像・記事・YouTube 動画から詳細を抽出する**(フェーズ0で動画を探してフレーム化し、建物ごとの写真一覧を `docs/kusatsu/refs/` に作る。YouTube Shorts は使わない。フレーム・画像はテクスチャにせず、リポジトリに入れない=`.gitignore`。保存先は `reference/kusatsu/`)。出典 URL は `docs/kusatsu/sources.md` に記録。
3. 公開: フェーズ6でユーザーに確認。

## 進み具合

- 計画作成: 2026-10-10
- フェーズ0 資料と範囲: 済(2026-10-10)
  - 原点=湯畑(OSM relation 12852884 の重心 36.622927, 138.596740)、+X=東、+Y=北、Z=標高。半径200 m。
  - OSM: `plateau_data/kusatsu_osm.json`(半径260 m、910 要素、範囲内建物223棟、高さタグ0・階数タグ22のみ)。**PLATEAU に草津町は無い**(群馬は前橋・桐生・館林のみ)ので、標高は国土地理院 DEM5A(`plateau_data/kusatsu_dem.json`、4 m 格子、±300 m、1137〜1198 m)、建物高さは階数(OSM+動画・記事)で決める。取得は `fetch_kusatsu.py --osm --dem`。
  - `inventory.md`(建物棚卸し。階数・屋根・外壁の多くは「要確認」)、`sources.md`(記事・動画の出典)、`refs/index.md`(場所ごとの動画時刻索引)。
  - 動画5本(歩き・通常動画、Shorts でないことを確認)を `reference/kusatsu/`(gitignore、約2.6 GB)に保存、3秒ごとのフレームと一覧シート(`tools/kusatsu_frames.py extract/sheet/overview/sheets`)を作成。
  - 申し送り: 建物ごとの正面フレームの選定と階数・屋根形の確定がフェーズ3の前に必要。湯畑の見せ場(木樋・湯滝・見学デッキ・石畳・柵)の写真はフェーズ2用に十分ある。夜景は作らない。
