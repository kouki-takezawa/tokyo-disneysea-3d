# 草津温泉 湯畑ジオラマ計画(2026-10-10、同日改訂)

ユーザー指示(2026-10-10):「草津温泉街、湯畑周辺のジオラマを作る。個人利用なので店の看板も実名でOK」
改訂(同日):客は入れない・動かない・360度回して見られる・本物のジオラマのようにリアルに忠実に(建物の凹凸と装飾、地形の傾きと高低差も)・フェーズごとに /clear・モデルとサブエージェントを計画に入れる。

## 方針

- **形**: 本物のジオラマ。湯畑を中心に半径 200 m(西の河原通り・光泉寺まで)の地面を切り出し、**台座の上に載せ、360度ぐるっと回して見られる**。Three.js の Web ビューア(ドラッグで回転・ズーム・上下の角度、自動で回る台座モードも)。スマホ対応。公開するかはフェーズ最後にユーザーに確認(看板が実名のため)。
- **完全に静止**(2026-10-10 ユーザー指示):人・車・湯の流れ・湯けむり・雲などの**動くものは作らない**。湯滝や湯の流れも形と色(白濁した水面・湯の花)で表す。客はいない。夜景は作らない。
- **リアルに忠実**(`feedback_realistic_first`):初版から写真と並べて確認してから報告。必ず入れるもの:
  - **地形の傾きと高低差**: 国土地理院 DEM5A の実測標高を使い、高さは**誇張しない(1:1)**。湯畑が底で光泉寺側と西の河原側が上る坂、擁壁、法面、段差、階段の段数まで再現。
  - **建物の凹凸と装飾**: 壁の出入り、軒の出、庇、屋根の勾配と瓦・鉄板の割り、棟、破風、懸魚、格子、窓枠、サッシ、ベランダと手すり、柱・梁の化粧、漆喰・板張り・タイルの目地、奥まった開口、エアコン室外機、配管、雨樋。
  - **湯畑**: 石縁の積み、木樋(7本)の継ぎ目と傾斜、湯の花の白い付着、湯滝、見学デッキの木階段、柵、灯籠。
  - 小物: 提灯、のれん、看板(実名)、自販機、街灯、電柱・電線、標識、石畳の割り。
- **看板は実名**(ユーザー許可)。読み取れたものだけ入れ、読めないものは入れない(推測で書かない)。
- **資料**: ユーザーは写真を用意できない。ネットの画像・記事・YouTube 動画から抽出する(フェーズ0で済。`reference/kusatsu/` に動画・フレーム、索引 `docs/kusatsu/refs/index.md`、出典 `sources.md`)。YouTube Shorts は使わない。Street View は目視参考の数枚のみ。フレーム・画像はテクスチャにしない・リポジトリに入れない。
- **作り方**: OSM(建物の外形・道・水)+ DEM(標高)+ 動画フレームで高さ・屋根形・装飾を決める。Blender 5.2 で手続き生成 → glTF → ページ。宇都宮ビューア・TDL モックの書き出し手順を流用。
- 木・植え込みは動画で確認できた位置だけ(`feedback_plants_confirmed_only`)。
- 他タブの未コミット変更(`src/export_mock.py`、`tools/organize_frames.py`、`output/disneysea/models/woody*`)は勝手にコミット・破棄しない。**Blender の同時ヘッドレス起動は禁止**(他タブと衝突する。サブエージェントの並列作業は「資料の読み取り・スクリプト作成」に限り、Blender の実行は1つずつ)。

メインの会話(段取りと確認・報告だけ)は軽く保ち、実作業は各フェーズごとに**サブエージェント**へ渡す。モデルは `model` 指定で切り替える。

各フェーズ = 1コミット + push。終わったら下の「進み具合」に `済(commit、日付)` と要点を追記。

## 運用(トークン節約)

- **1会話 = 1フェーズ**。各フェーズの終わりに必ず、(1) コミットと「進み具合」への追記、(2) 次フェーズへの申し送りを `docs/kusatsu/handoff.md` に上書き(やったこと・次にやること・落とし穴・使ったファイル)、(3) ユーザーに**「/clear してから『草津計画のフェーズN から』」**と案内する。次の会話は `plan.md` と `handoff.md` だけ読んで始める。
- 画像は大量に読まない。一覧シート(縮小)で位置を探し、必要なフレームだけ開く。1回の確認で開くのは数枚まで。
- 大きいファイルは grep で位置を探して部分だけ読む。
- 確認は数値(三角形数・描画数・ファイルサイズ)+縮小スクショ1〜2枚と動画フレームの比較。
- サブエージェントへの指示は自己完結に書く(計画書のパス、対象、成果物、触ってはいけないもの)。報告は要点だけ返させる。
- Blender の同時ヘッドレス起動は避け、実行前に他のプロセスが無いか確認する。
