## 座標換算

- 原点 = 湯畑重心(OSM relation 12852884、北緯 36.622927 東経 138.596740)。平面は `x = (lon-LON0)*111320*cos(LAT0)`、`y = (lat-LAT0)*110540`(m)。
- **Blender の Z = 標高(海抜 m) - 1153**(`ZBASE`)。DEM5A の標高をそのまま使い、誇張しない(1:1)。
- glTF(Y-up)/ Three.js: `x = 東`、`y = Blender Z`、`z = -北`。つまり Blender (x, y, z) → Three (x, z, -y)。例: 石段の下端 OSM (-49.7, -75.0)、海抜 1158.4 は Blender (-49.7, -75.0, 5.4)、Three (-49.7, 5.4, 75.0)。

## 高さ場の作り方(1:1 の上にある「手入れ」)

DEM(4 m 格子)を Catmull-Rom で補間 → 1 m 格子に直し、下を重ねる(順番が重要)。
1. **道**(OSM highway、トンネル・階段・area を除く 149 本): 縦断を約 21 m の移動平均でなだらかに。半幅は trunk 4.5 / residential 3.0 / unclassified 2.8 / service 1.8 / pedestrian 2.5 / footway 1.1 / path 0.9 m。回廊の縁から 3 m で元の標高へ戻る(これが法面・切り土・盛り土になる)。
2. **湯畑の池**: 池は OSM が両端の小さな 2 ポリゴンだけなので、**両端の円 + 首(半幅 4.2 m)の瓢箪形**に作り直した(軸長 53.6 m、全長約 66 m)。縁(周囲 1〜5 m の標高の中央値)を平らにし、内側は 1.1 m 掘る。
3. **建物の敷地**(247 棟): 外形の内側を内側の平均標高に均し、外へ 3 m でなだらかに戻す。そのあと道の芯を再度平らにする(敷地の縁が路面に食い込まないよう)。
4. **石段**: カード D_stairs の数値で、6 区間(第1段 55、山門の通路、第2段 36、踊り場、第3段 22、本堂前)。さらに OSM の steps 19 本を 1:1 の段にした(蹴上 16 cm 目安、段数は標高差から)。石段の下の地面は線形の斜面に均す。
5. ごく弱い平滑(敷地の内側と池の内側は除く)。

## 作ったもの(地形側 terrain.glb、約 99k 三角形)

- 地形: 半径 200 m の 2 m 格子円盤(縁の頂点は円に載せる)。頂点色は土・岩・敷地の土間・池の底。草木は置かない。
- 台座: 縁から下へ地層の断面(表土・ローム・火山灰・礫・岩盤の 6 層、深さは波打つ)、最低標高 -15 m の位置まで(Blender Z -26.1)、その下に暗い木の盤(半径 208.6、厚み 8 m)。縮尺なし。
- 道: 地面に張った帯(アスファルト/石畳風の面ごとの色むら)、歩行者エリア 3 面、山門の板敷・踊り場・本堂前。高さは地面 +7〜9 cm、ビューアで polygonOffset。
- 水: 湯畑(乳白の青緑、平面)、光泉寺の小池(暗色)。
- 石段・擁壁(`Stairs_and_Walls`): 石段は 1 段ずつ(3 枚の石で継ぎ目がずれる)、御影石の袖、主階段と副階段(グレーチング風の暗色)の境に手すり+青い支柱。擁壁は OSM retaining_wall 27 本を高い側の地面〜低い側の地面で立てた石の壁。
- 建物(仮、`buildings_A..D.glb`、合計 12.6k 三角形): OSM の外形+基礎帯+壁+屋根。階数は OSM タグ(30)>カード/名前の上書き>面積(小=2 階、他=3 階、700 m2 以上=4 階陸屋根)。屋根は OBB の長軸に棟を通した切妻(傾き 0.4〜0.6)、5 階以上・450 m2 以上は陸屋根。`buildings_index.json` に id・名前・区域・階数・屋根・pad_z・外形がある(フェーズ5〜8で該当 id を外して本物を置く)。

## 落とし穴

- `.gitignore` は先頭が `/*` の許可リスト。`kusatsu/` と `kusatsu-diorama/` を `!` で許可しないとコミットされない(追加済み)。
- **Blender 5.2 の頂点色マテリアル**: `ShaderNodeVertexColor`(`layer_name='Col'`)を Base Color につなぐ。glTF 書き出しは `export_vertex_color='MATERIAL'`。頂点色はリニアなので `srgb()` で変換して入れる。成功済み。
- Draco: 位置の量子化を地形 16 bit、建物 14 bit。three 側は `DRACOLoader.setDecoderPath('./lib/draco/')`(wasm は `lib/draco/` に置く。`python -m http.server` は `.wasm` を正しい MIME で返した)。
- 道の帯と地形は別メッシュ。重なって見えるのを `polygonOffset` と高さ +7〜9 cm で回避している(`Roads`、`Stairs*` の名前で app.js が判定)。名前を変えると効かなくなる。
- Python の `hash()` は実行ごとに変わる → 建物の色は `zlib.crc32`。
- bash の heredoc で日本語を含むと文字化けすることがある(ファイルは Write で作る)。`python` の標準出力は `PYTHONIOENCODING=utf-8` を付ける。
- Playwright MCP のスクショは作業ディレクトリ以下にしか保存できない。

## 見えた問題・未対応

- 建物の敷地を均した跡が、建物を隠すと穴(切り土)に見える。建物を本物に置き換えるときに、擁壁・基礎・法面として整える。
- 擁壁は地形が滑らかなままなので、斜面に薄い壁が刺さったように見える所がある(地形に段差を入れていない)。
- 湯畑の池は仮の瓢箪形(位置・大きさは OSM の両端ポリゴンから)。縁の石積み・周回路・柵・湯滝・木樋はフェーズ3。池の周りの舗装も未(道の帯と地形色のみ)。
- 屋根は切妻と陸屋根だけ(寄棟・入母屋・軒の出なし)。壁の色は仮。階数はほぼ推定。
- 軽量用の別メッシュ(三角形の間引き)と影の CSM、空のシェーダー、雲は未実装(フェーズ11)。
- 夜景・動くもの・木はなし(方針どおり)。看板の実名はまだ入れていない。
