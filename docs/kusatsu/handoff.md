# 草津計画 申し送り(フェーズ1 → 2)

- 済: フェーズ0(資料)、フェーズ1(建物の確定。`cards/`、`inventory.md` 第8節)。
- 次: フェーズ2 地形・台座・ビューア。座標は原点=湯畑重心、+X=東、+Y=北、Z=標高(1:1、湯畑≈1153 m を Z=0 にずらして使うかはフェーズ2で決めて書く)。
