# C_yukitaki_lane 湯滝通り(西の河原通りの北側の裏通り)の店並び

区域C。通りの名前は路地の標柱「湯滝通り」(W 18:54 で読めた)。OSM way 89004799(service、名前なしで OSM は「湯滝通り」)。確度: 通り=高、店の割り当て=低〜中。

## 通りの形と高さ
- 経路(OSM): (-172,66) → (-160,78) → (-135,85) → (-108,72) → (-88,68) → (-68,74) → (-47,81) → (-23,71) → (10,41)。
- DEM の高さ: (-160,78) 1153.7 m、(-108,72) 1151.4、(-68,74) 1151.1、(-23,71) 1150.0。西の河原通り(1155〜1156 m)より 4〜5 m 低い。つまり、2 本の通りの間の建物(奈良屋、群龍館、山形屋の裏)は、南面が 1 階低く北面が地下側に下がる、北に落ちる斜面に建つ。
- 路面は幅約 3.5 m のアスファルト、中央に薄い排水の溝(W 18:xx の濡れた路面)。歩道なし、建物の外壁が直接立つ。(W 19:00 以降)

## 動画で確認できた建物の外観(名前は読めていないもの)
- 湯滝通りの西寄り(W 18:21〜18:45、(-150,80) 付近?): 黄色の漆喰壁に黒い柱・梁を見せた 2 階建て(切妻の黒い瓦屋根、庇の瓦、木の格子窓)と、杉板張りの赤茶の 2 階建ての店(W 18:45)。確度 低(位置)。
- W 19:48〜20:06: 木のデッキ付きの新しいガラス張りの店(茶色の縦ルーバー、軒の木の先端が斜め)と、ドラゴンの向かいにあたる店。茶色の大きなガラスの店はシートでは看板の英字が読みきれない=不明(W 20:12)。
- W 20:36 (f_000413): 通りは右に曲がり、右(南)に白漆喰+黒い柱・梁を見せた 3 階建て(出の深い黒い庇、赤い提灯、軒の小窓、電気メーターと電柱)。左(北)は灰ベージュの 2 階建て(切妻、木の外階段つきの 2 階)と、オレンジ色の木柵の空き地(駐車場、白い SUV)。奥(東)に湯川方向の緑の斜面。
- W 20:48 (f_000417): 右(南)に黒い板張りの小さな屋台風の飲食店(赤い提灯と赤い暖簾、銀色のダクトが外壁を這う、庇に電球の列、黄色の木の看板板)。看板は読めず=不明。左は瓦屋根(本瓦風の小庇)の古い 2 階建て木造。奥の白い大きな旅館に「ヨ…」風の屋上看板(読めず)。
- W 20:57 (f_000420): 通りの東端近く。右(南)に白漆喰+黒い真壁の 3 階建て(格子窓、木のバルコニー、小庇に瓦、壁から突き出す縦の木札=読めず)、足元に低い植え込み。左(北)はグレーの外壁の近代的な 3 階建て(1 階がシャッター、酒の赤い看板、自販機 2 台、石の乱積みの角)。この右の棟が OSM の (-45,73)〜(-33,69) 付近(キッチン 笑・山茶郷の近く)に当たるとみる=低確度。
- W 21:06 (f_000423): 通りが湯畑の北側の広場へ出る端。右(南)は風化した杉板張りの 3 階建て(アルミサッシの窓、雨樋、出窓の庇)、左(北)は灰色の小タイルの外壁の建物(縦長の幟「地酒…」の緑の旗)。奥に湯畑の木の柵と湯けむり、白い高い旅館。
- 通りの電柱: 通りの右(南)側に細い木・コンクリの電柱。道路標識(青い丸「自転車を除く」)を W 21:06 で確認。
