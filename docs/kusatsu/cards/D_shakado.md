# D_shakado 光泉寺 釈迦堂(茅葺き)

確度: 位置・規模=高(OSM)、形・外装=中〜高(動画)、掲示の文字=一部不明。

## 位置・外形

- OSM way 912422963(name=釋迦堂、historic=wayside_shrine)。中心 (-110,-97)、z 約 1179〜1180。
- 外形頂点: (-114.5,-91.5)、(-113.3,-100.0)、(-111.3,-99.7)、(-111.0,-101.7)、(-107.4,-101.1)、(-107.7,-98.8)、(-105.8,-98.5)、(-107.1,-90.4)。主屋は約 7.5 m(東西)x 8.6 m(南北)、南に **向拝(約 3 x 3 m)**が出る。
- **正面は南(方位角 約 185°)**。参道は本堂前から南へ約 13 m、石灯籠が両側に並ぶ細い石畳の道(幅 約 2.5 m)(f_000493〜497)。
- OSM 座標のずれ補正: なし(参道の長さと向きが動画と合った)。

## 階数・高さ

- **一重**。高さは棟まで 約 7〜8 m(推定: 向拝の柱高 約 3 m と、茅葺きの屋根が柱高の約 1.4 倍の見かけ)、軒先は低く(約 2.5〜3 m)垂れ下がる。確度 中。

## 屋根

- **茅葺きの寄棟(大きく反った軒、厚い茅)**。屋根の厚みは約 0.5 m で、軒先は丸みを帯びる(f_000497)。屋根は茶〜灰褐色の古茅。
- 屋根の頂部正面に**小さな破風(千鳥破風状)と棟飾り**が載る(f_000497 上)。
- 向拝は茅葺きの軒が前に張り出し、屋根と一体。軒先に小さな**白い金具の列**(軒下の装飾金具)が見える。

## 外壁・柱・装飾

- 柱・梁・高欄は**朱(暗い赤)**、壁は**暗い茶**(古い塗り)。**縁側(朱の高欄)が全周に巡る**(f_000497)。
- 向拝柱の上部に**白く塗った木鼻・組物(獅子鼻風)**(f_000497 中央)。正面に階段(3 段、木、朱)。
- 壁に**緑の連子窓(丸みのある火灯窓)**が左右に 1 つずつ(f_000497)。
- 扉の中は暗く、仏壇が見える。正面に**白い幟(縦長、黒文字)**が柱の脇に立つ。文字は「○咲如来」と読めるが、1 字目が判読不能(「運」か「遅」に見える。f_000497)。
- 向拝の前に**石香炉(丸い)**と、参拝者が立つ石敷き(幅 約 2 m)。
- 参道の両側に石灯籠が並ぶ(春日型・六角型の混在、高さ 約 2 m)。参道脇に竹の杭とロープの柵(f_000493, R 25:00〜25:09 の沿道)。
- 周囲は赤松と落葉樹の林(位置のみ、植物の確認はフェーズ 10)。
