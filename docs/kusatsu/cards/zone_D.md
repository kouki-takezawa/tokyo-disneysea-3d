# 区域D(光泉寺の境内・石段・参道沿い)まとめ

フェーズ1の担当区域D。原点=湯畑中心、+X 東、+Y 北、m。資料は主に R(rSRX6OiqD3M)の 19:30〜27:00(石段と境内の歩き)。W(雨)の 0:20〜0:30 で立体駐車場の入口。使った画像は約 50 枚。

## 最終境界

- x < -25 かつ y < -80、かつ原点から 200 m 以内(円の外は作らない)。
- 範囲内の建物・地物は光泉寺の境内(約 x -141〜-65、y -88〜-152)、石段(x -50〜-100、y -75〜-112)、石段下のぬ志勇旅館、湯畑観光駐車場(約 x -98〜-34、y -131〜-199)、南の小建物。

- **境界で他区域に接する**: 御座之湯 (-74,-55)(石段の北西隣)、白旗の湯・熱乃湯(y > -80 側、別区域)、ローソン (-12,-187) と食事処(x > -25 で別区域)、ぐんまみらい信用組合 (-29,-120)(境界上)。
- **高低差**: 石段の下端 z 1158.4 → 本堂前 z 1178.7(約 20 m)、立体駐車場の地盤 z 約 1179。

## 区域全体の特徴

- **斜面**: 湯畑(z 1153)から光泉寺へ南西に約 20 m 上る急斜面。境内は z 1178〜1181 の**高台の平場**で、本堂・釈迦堂・五重塔・庫裏が並ぶ。石段の下は湯畑の広場(石畳)に接する。斜面は笹・低木、赤松・落葉樹の林(位置だけ。植物はフェーズ10)。
- **擁壁**: 石段の左下と右の途中に玉石積み(丸みのある自然石)の低い擁壁(1.2〜1.5 m)。トイレ棟の北〜西に OSM の擁壁(長さ 約 35 m)がある(未確認)。
- **配置**: 石段 → 山門(石段の途中、標高 1167)→ 踊り場 → 上段 → 境内。境内は本堂(西)、釈迦堂・不動堂(北)、鐘楼(石段の上の縁)、五重塔(北西の端)、庫裏(南)。本堂の前の参道が石段の延長にまっすぐ西南西へ通る。
- **色調**: 山門・本堂の柱・鐘楼・釈迦堂が**朱(赤)**、壁が**白漆喰**、屋根が**灰〜銀灰の金属板**(山門・本堂)と**茅葺きの茶**(釈迦堂)。石は**灰色の花崗岩**。石段の下は**ぬ志勇旅館の白と黒**、右隣の**御座之湯(オレンジ〜茶の杉板と灰の杉皮葺き風)**が隣接(別区域)。境内の地面は**薄茶の締まった土**と灰色の切石の参道。
- **のぼり旗**: 赤い幟「奉納 南無薬師如来」(青い竿)が石段の右手すりと境内の道沿いに多数並ぶ。

## フェーズ8(制作)での注意

1. 石段は高低差を 1:1 で再現する(DEM と OSM の steps)。段数は推定(約 113 段)で、各段の高さは約 16〜17 cm。実装は段の数から逆算し、下端 z 1158.4 → 上端 z 1178.7 に合わせる。
2. 主階段と右の副階段(グレーチング)、手すり、袖壁、両脇の擁壁の位置関係(f_000413, f_000431)を踏襲する。
3. 山門は石段の途中に載る(通路が板敷)。石段を山門の内側で一度切る(踊り場が 2 つ)。
4. 本堂は軸が東から北へ 21.5°回る。五重塔も同じ。参道は本堂の正面中央に合わせる。
5. 釈迦堂は南向き、茅葺き(質感: 厚い茅、軒先が丸い)。
6. 五重塔の周りは工事の柵(オレンジと黒)と裸地。動画時点を写すなら柵あり、写さないなら省く(ユーザー判断)。
7. 看板に実名を入れてよいのは、動画で読めたものだけ: 「草津山 光泉寺」の石碑(真言宗 豊山派)、ぬ志勇旅館、湯畑展望露天風呂、湯畑観光駐車場、お守り頒布所、幟「南無薬師如来」、賽銭箱の「浄財」。その他(本堂の扁額、各堂の名称板、湯喜堂)は文字を入れない。
8. 立体駐車場は入口側(東面)だけ作り込めば足りる(他の面は見えず、ジオラマの縁で切れる位置)。
9. 木立は位置のみ記録: 釈迦堂の参道の両側と境内(赤松多数)、本堂の前庭(松の古木 2〜3 本、f_000455)、石段の第2段の両側(笹・低木の斜面)。フェーズ10で確認できた位置だけ。
