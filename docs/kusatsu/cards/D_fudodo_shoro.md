# D_fudodo_shoro 光泉寺 不動堂・鐘楼・手水舎

確度: 不動堂=中(位置は OSM、動画で黒屋根の小堂を同定したが名称の文字は読めず)、鐘楼=高、手水舎=中。

## 不動堂

- OSM way 1311927452(name=不動堂、historic=wayside_shrine)。中心 (-95,-100)、4x4 m(頂点 (-97.4,-98.8)、(-94.1,-97.3)、(-92.5,-100.7)、(-95.7,-102.3))、z 約 1175.4。
- 動画での同定: 鐘楼から山門へ向かう道の右(南)に、**黒い宝形(方形)屋根の小堂**があり、石灯籠が脇に立つ(R 25:42〜26:12、f_000515〜524)。OSM の位置関係と合う。**名称の文字は読めず**。確度 中。
- 形(推定): 一重、方 1 間(約 3 x 3 m)、**宝形造の黒い屋根(瓦か黒塗りの金属板)**、軒先が薄い。壁は白漆喰、柱・扉は暗い赤。
- 正面の方角: 北(参道側)を向くと推定(確度 低)。

## 鐘楼

- OSM way 1311927451(man_made=campanile、note=鐘楼)。中心 (-96,-106)、約 4.2 x 4.2 m(頂点 (-98.6,-104.8)、(-94.7,-103.4)、(-93.2,-107.4)、(-97.2,-108.9))、z 約 1176.6。
- 位置: 第3段の石段の登り口の右側(北西側)、石段の縁に載る。**石垣の上**で、手前(石段側)に低い石の台と黒い刻字の板(寄進者名。細かい字で判読不能)(f_000511)。
- **一重、方 1 間の吹き放ち**。**4 本の朱の柱+朱の貫(横木)**、中に**梵鐘(黒い鋳鉄の鐘)**が吊られる。**屋根は暗褐色〜黒の宝形(単層)**で、軒の垂木は朱に白(垂木の木口に白い)(f_000507, f_000511)。
- 高さ(推定): 軒高 約 3 m、頂部 約 5〜5.5 m。確度 中。
- 付近に**赤い幟「奉納 南無薬師如来」**が 5〜6 本並ぶ(青い竿)、黒い鋳鉄の洋風ランプ柱(f_000507)。
- 鐘楼の足元の一部に低い**石製の手すり(石の笠木、稲妻のような擬宝珠風)**。

## 手水舎

- OSM way 1311927453(man_made=water_tap、note=手水)。中心 (-91,-104)、約 2x3 m、z 約 1176。
- 動画では、踊り場の右(北西)の**切妻の小屋根を載せた柱の簡素な手水舎**(暗い瓦、黒い柱 4 本、石の水盤)(f_000442 右、f_000445)。柱は黒褐色、基礎は石積み。高さ 約 3 m。確度 中。
- 柱の根元が玉石の布積み(石積み)で、水盤が石の長方形。
