# D_yukido 湯喜堂(山門の先、石段第2段の左の小堂)

確度: 位置=中(OSM と動画の見え方が合う)、名称=OSM のみ(動画で看板を読めず)、形=中。

## 位置・外形

- OSM way 955188994(name=湯喜堂、historic=wayside_shrine)。中心 (-74,-100)、約 3x3 m の四角(頂点 (-75.1,-100.1)、(-73.5,-102.1)、(-71.4,-100.5)、(-73.0,-98.5))、z 約 1169。
- 山門を出て、第2段の起点の**左(南東)側**。登る人から見て左に張り付くように建つ(f_000430、R 21:27)。
- 正面の方角: 北東(山門の出口側、石段の登り口から見える側)。確度 低。

## 形(動画: f_000430、f_000526)

- **一重、方 1 間(約 3 x 3 m)**。壁は**白漆喰(平らで、ほぼ無地。角が丸い大壁)**、高さ約 3 m。
- 屋根: **黒褐色の瓦または板の宝形(または寄棟)**、軒先の下に**暗い茶の組物(出組風)と垂木**が見える(f_000430 左上)。軒の出は約 0.6 m。
- 扉: 左側面に暗い木の格子戸(f_000430 の左端)。
- 名称の看板は読めず。**「湯喜堂」の名は OSM のみで、動画では確認できない。**

R 21:21(f_000428)、21:27(f_000430)、26:15〜26:21(f_000525〜526、境内側から屋根)。
