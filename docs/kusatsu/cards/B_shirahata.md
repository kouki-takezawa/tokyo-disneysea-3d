# B_shirahata 白旗の湯と白旗源泉(区域B)

## 白旗の湯
- OSM: way 954786834(10頂点、building=commercial、name=白旗の湯)。重心 (-41,-40)、約 12.1 x 9.5 m(長辺は +X から 66°)、面積 105 m2。外形角: (-49,-43) (-44,-32) (-35,-35) (-37,-39) ほか。(-38,-40) に「白旗の湯由来」の案内(OSM node)。
- 正面(玄関): 東(熱乃湯・観光案内所と同じ南西の道に面する側)。Y 1:54〜2:03、R 27:48〜28:09。
- OSM 座標のずれ: 補正なし。
- 確度: 玄関まわり=高、本体の屋根・規模=中、階数=中。

### 階数・高さ
- 平屋+屋根裏(本体は2階建て相当の高さの大屋根)。Y 1:54(f_000039): 玄関ポーチの軒 約 3 m、本体の軒 約 4.5 m、棟 約 7.5 m(推定)。
- 玄関のポーチ: 切妻の小屋根、軒 約 2.8 m、棟 約 4.2 m。

### 屋根
- 本体: 灰黒の本瓦風の瓦(Y 1:54 左、Y 2:00)、入母屋〜切妻。棟に小さな換気の妻(格子)。
- ポーチ: 向拝風の切妻、軒先はやや反る(Y 2:03)。濃い茶の木部(破風板、梁の出)。妻に乳白の漆喰。
- 左隣の木の小さな案内所(板張りの小屋、灰茶の薄板の屋根。Y 2:00)。

### 外壁
- 濃い茶の板張り(横板、Y 2:03 玄関左右)。玄関の格子戸(縦格子、腰に板)。
- ポーチの妻: 乳白の漆喰。ポーチ床: 木の縁側風(濃茶、段1つ)。

### 装飾・付属物
- 板額(赤茶の地に白〜金の字)「白旗乃湯」と読める(Y 2:03、文字が小さく、確度中)。
- 白い無地の暖簾(上の紐、房。Y 2:03 で読めた=文字なし)。
- 「女湯」の紙(Y 2:03 で読めた。橙の紙に黒字)、掲示物数枚。
- 右手の小庇に黄みの木の郵便受け(箱)(Y 2:03 右)。
- 手すり: ポーチの木の手すり(1段の昇り)。

### 櫓風の格子の小塔
- 白旗の湯の背後〜隣に、黒の格子(井桁の木組み)と黄みの窓を持つ小さな塔(3層程度の高さ)がある(Y 1:54 左上、R 27:48〜28:09 の一覧、R 20:12(f_000405) 右)。白旗の湯の一部か隣の建物かは未確定。高さ 約 9 m(推定)。

## 白旗源泉の屋根(別棟)
- OSM: way 955804968(building=roof)。重心 (-52,-64)、約 7.4 x 3.9 m(長辺は +X から 27°)。
- 構成(Y 2:24〜2:33): 木の柱で支える大きな切妻の差し掛け屋根(板葺き、灰茶)、木の額「白旗源泉」(Y 2:27〜2:33 で読めた)、白い布(中央に染め抜きの「白旗」の字、提灯の下がる)。柱の間は低い格子の手すり。源泉の泉は石で囲った細長い湯だまり(Y 2:36〜2:51)。
- 屋根は低め(軒 約 2.6 m、棟 約 4.5 m、推定)。提灯が軒から3〜4個(R 27:12 で白く丸い提灯)。
