# B_kusatsukan 草津館と湯路広場側の黄土色の旅館(区域B)

- OSM: way 954786833(18頂点、building=hotel、name=草津館)。重心 (-61,-40)、約 23 x 23 m(軸は +X から 66°)、面積 293 m2。外形角: (-72,-40) (-70,-35) (-67,-37) (-66,-35) (-57,-39) (-54,-32) (-52,-33) (-50,-28) ほか(出入りの多い外形)。隣に無名の (-67,-32)(954786836、約 19.6 x 8.8 m)があり、同じ建物の別棟の可能性が高い。
- 同定の根拠: 湯路広場の石積みテラスの奥に立つ黄土色の旅館(K 7:30 f_000151、R 20:00 f_000401 左)。OSM でこの付近の hotel タグは草津館だけ。看板の文字を直接読めていないので確度は中。
- 正面: 湯路広場の側(東〜南東)に1階の店舗と玄関。広場とアーケードを挟んで道に面する。
- OSM 座標のずれ: 補正なし。
- 確度: 位置と色=中、階数=中(K 7:30 で5層、R 20:00 では下の3層のみ見える)。

## 階数・高さ
- K 7:30(f_000151)で窓の段を数えて5階建て(1階の店舗+上に4段の客室)。1階 約 4 m(庇まで)、2階以上は各 約 3.1 m、軒 約 16 m、屋根を入れ最高 約 17.5 m(推定)。南側の斜面の下から見ると石積みの擁壁(約 1.5 m)の上に立つ。

## 屋根
- 低勾配の寄棟、濃灰の瓦または薄い屋根材(K 7:30 右上)。屋根面は見えず軒線のみ確認。

## 外壁
- 黄土色〜山吹色の吹付またはモルタル塗り、各階の間に濃茶の水平帯(胴蛇腹風の板)が通る(K 7:30、R 20:00)。
- 窓: 各階2〜4連の小さな窓、濃茶の枠、窓の下に細い鉄(または木)の手すりのベランダ風の出窓(K 7:30)。
- 1階: 濃茶の板壁とガラスの店舗、軒下に庇(濃灰の瓦の腰屋根)、白い丸い紙提灯が横に6個前後並ぶ(R 20:00 f_000401 左)。
