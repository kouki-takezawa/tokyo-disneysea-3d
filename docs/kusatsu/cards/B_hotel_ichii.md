# B_hotel_ichii ホテル一井(本館・別館・西館)(区域B)

## 本館
- OSM: way 605546948(6頂点、building=hotel、building:levels=8、name=ホテル一井 本館)。重心 (-57,6)、外形角 (-54,24) (-58,22) (-72,0) (-78,-12) (-52,-28) (-30,10)。約 31.5 x 44.1 m(軸は +X から 59°)、面積 約 1,360 m2(bbox 49 x 52 m)。湯畑の北西側を回る道に面した大きな6角形。
- 正面: 東〜北東の道(湯畑の北西側の歩道)と、西の河原通りの入口側(北)にも店舗の面。R 1:15〜1:27(f_000027)、R 29:27〜29:48(f_000591)、S 3:03(f_000062)。
- OSM 座標のずれ: 補正なし。
- 確度: 8階(OSM)と見た目は一致=高。意匠の細部=中。

### 階数・高さ
- 8階(OSM)。1〜2階は古典様式風の高い基壇(各 約 4.5 m)、その上の客室階は各 約 3.1 m で6階分。屋上までの高さ 約 28 m、塔屋 約 3 m を加えると最高 約 31 m(推定)。
- R 20:12(f_000405)の「一井」ロゴの塔は本館南側の高い塔屋で、一番高く、細い。

### 屋根
- 陸屋根(平らで、塔屋と設備が載る)。基壇の上に手すり壁(バラスター付きの白い欄干)がある(R 1:18 f_000027)。

### 外壁
- 基壇(1〜2階): クリーム色〜白の石造風(漆喰または石張り)、ピラスター(角柱の形)、出の深い軒蛇腹(歯形の飾り)、大きな長方形の窓(濃灰のサッシ、2階は横長)、1階は丸い隅の列柱廊(R 1:18)。西の河原通り側(R 29:27〜29:48 f_000591)は1階がガラス張りの店舗(濃灰の石タイル歩道)、壁の上に円形の飾り板。
- 上階(3〜8階): 白の吹付、小さい窓が横に並ぶ(各階 各面に8〜12枚)、窓の下に水平の細い帯。

### 看板
- 「一井」のロゴ(四角の枠に漢字の一井、R 20:12 f_000405 で塔の最上階に確認。読めた)。
- 西の河原通り側の玄関前マットに「HOTEL ICHII」風の英字と「一井」(R 29:30 f_000591 の足元。緑のマット)。
- 1階の店舗の看板「たばこ」(R 29:24 で一覧から読めた)。そのほか店舗名は不明。
- 小さな角板「一井」(R 29:48 の一覧)。

## 別館
