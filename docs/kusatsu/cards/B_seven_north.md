# B_seven_north 湯畑の北側の建物(セブン-イレブン・北側の並び)(区域B)

区域Bの北側(x が -25 以上、y が 25 超〜70)。フレームで確認できたのはセブン-イレブンとその左隣の黄土色の宿だけ。そのほかは未確認。

## セブン-イレブン
- OSM: way 954629632(4頂点、building=retail、名前なし)。重心 (-11,29)、約 19.4 x 10.9 m(軸は +X から 59°)、面積 211 m2。外形角: (-18,25) (-9,19) (1,36) (-8,41)。OSM の node「セブン-イレブン」は (-8,33)。
- 正面: 南の道(湯畑の北西を回る道)側にガラス張りの店頭。R 29:18(f_000586 右)、S 3:03(f_000062 右)、W 1:31(f_000091 の左)。
- OSM 座標のずれ: 補正なし。
- 確度: 位置と店名=高、階数・屋根=中。

### 階数・屋根・外壁
- 2階建て。1階の店舗(ガラスの店頭、濃灰のサッシ、日除けなし)、2階はクリーム色の吹付の壁に小さな窓(1〜2枚)、低勾配の寄棟(濃灰の金属または瓦)。R 29:18 では灰色の大きな寄棟の下に横長のガラス窓帯が見える。軒 約 6.5 m、棟 約 8.5 m(推定)。
- 店頭: 看板帯(白地に橙・緑・赤の横線の「7 ELEVEN」のロゴ、S 3:03 f_000062 で読めた)、四角い「7」の標識(R 29:18 f_000586 右、W 1:31 でも確認)、店前に積まれた水色のケースと台(W 1:31 で青のカゴ、橙のカゴ)。
- 看板: 「7-ELEVEN」(読めた)。そのほか店頭の青い立て看板に「カピバラの赤ちゃんが…」と読める文章(S 3:03 右端。キャンペーン告知、置くか要判断)。

## 黄土色の旅館(セブンの左隣)
- OSM: way 954629634 付近((-22,46)、約 14 x 17 m、building=yes、名前なし)。
- W 1:31(f_000091): 3階建て、黄土色の外壁、窓は小さな縦長、丸窓が1つ(最上階)、濃茶の大きな庇。縦長の看板があるが判読不能(「…泉屋」ふうに見えるが推測。不明とする)。
- 確度: 低。
