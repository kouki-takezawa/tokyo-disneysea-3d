# C_masunariya 益成屋(西の河原通りの入口・南側)

区域C。確度: 看板・位置=高、階数・屋根=中、外壁の細部=低。

## 位置・外形
- OSM way 954965052「益成屋」(hotel)重心 (-84,24)。外接 51 x 34 m、回転矩形 約 38 x 38 m(回転 60 度)、27 頂点で凹凸が多い(玄関棟と客室棟の連なり)。
- 正面(玄関・門)は北〜北東、西の河原通りの入口の交差点(約 (-57,32))に面す。門の前に「益成屋」の立て看板と木の柵、植え込み。
- 通りの高さ約 1156〜1157 m、建物の裏(西・南西)はやや上り。

## 階数・高さの根拠
- 玄関棟: 2 階建て + 入母屋の庇屋根(R 29:51 / f_000599 で、石灯籠と提灯の下の玄関屋根が一段低い入母屋、その奥に白壁+薄茶のタイル風外壁の棟が 3 階まで)。客室棟は 3〜4 階(R 29:54 奥)。確度 中。
- 見積り: 玄関庇の軒高 約 3.8 m、客室棟の軒高 約 10 m(3 階)、棟 約 13 m。

## 屋根・外壁・装飾
- 玄関屋根: 入母屋(黒〜濃灰の瓦、本瓦風の筋)、軒先の瓦当て。屋根の下に提灯(白)が吊られ、玄関先に石灯籠(R 29:51)。
- 客室棟の外壁: 白い漆喰壁と、薄茶色(レンガ色)のタイル張りの帯(各階の腰〜窓の下)、焦げ茶の木枠の窓。3 階にエアコンの室外機 2 台(R 29:51 の看板の上)。
- 門まわり: 木の縦格子の柵(高さ約 1.1 m、焦げ茶、R 29:51〜30:00)、植え込み、低い石組み(縁石)。
- 看板: 白地に黒の大きな「益成屋」、その上に細字「押花草の宿」「白旗源泉の湯 桧風呂」(R 29:57 / f_000600、K 13:30 で同じ看板を確認)。木の掲示板(ガラス戸付き、玄関の左)、小さな縦札も付く。読めた=高。
- 青い道路案内標識(「西の河原公園」「天狗山・白根山」「292」)が門の前の支柱に付く。

## 周辺(通り)
- 交差点: 角の路面に白い曲線の停止線。益成屋の門前の車止めポール(赤白のコーン状)。
- 益成屋の北側(右)に、茶色の車体+家紋マークの送迎バン数台が停まる(奈良屋の車、R 29:57〜30:03。作らない=動くもの)。
- 路面はアスファルト、歩道との境は白線。益成屋側(南/左)は低い縁石+ L 字溝。
