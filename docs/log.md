# 作業ルールと確認の記録

- **この端末(Blender なし)での作業は、毎回このリポジトリにコミットして push する。** コード、データ、確認に使った道具(`tools/`)、確認の結果(この節)、README の更新まで含める。別の端末で作業を引き継ぐため。
- Blender で作るときは、「[Blender で作るときの参考動画](blender.md#blender-で作るときの参考動画必ず見る)」の動画(と同じ投稿者のディズニーパーク関連の動画)を必ず参考にする。
- 確認に使う道具(Blender なしで動く):
  - `python tools/blender_smoke.py` — Blender 用スクリプトを、Blender の機能を空の代用品に置き換えて読み込み、構文・import・データファイルの有無を確かめる。
  - `python tools/aerial_overlay.py X0 Y0 X1 Y1 [OUT.jpg]` — モックのデータを国土地理院の航空写真に重ねて、位置を目で確かめる(範囲はローカル座標 m)。
