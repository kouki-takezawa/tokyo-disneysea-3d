# 範囲3 クリッターカントリー: 段階A 資料 (2026-10-04)

段階B(Opus)は新規 `src/ds_tdl_critter.py`(plain Python、Blender なし)1 本で 2 モデルを書き出す。範囲1・2 と同じ構成。コードはまだ無い。

- `tdl_crit_ground` … 地面・縁石・花壇・目印。`ds_ground.py` の `tdl_land_ground` の `cut_models` に追加(今は `tdl_plaza_ground, tdl_adv_ground, tdl_west_ground`)
- `tdl_critter` … 山・建物・小物・植栽・鉄道の木橋。`export_mock.py` の MODELS に 2 行足す(`("tdl_crit_ground","disneyland",[])` と `("tdl_critter","disneyland",["dlcrit"])`)。平の JSON は WEB_ONLY
- 下書き箱は `ds_disneyland.MODEL_KEYS` に新キー `dlcrit` を足して隠す(下表)。材質プレフィックスは地面 `CTG_*`、建物 `CT_*` を推奨。指示の `CC_*` は `ds_tdl_cinderella.py` が Blender の物体名に `CC_` を使っているので避けた(モックの材質名とは別物だが紛らわしい)
- ユーザー写真: `images/` にクリッター/スプラッシュ関連は**無い**(crystal_palace, ice_cream_cones, stitch_encounter, tomorrowland_terrace のみ)。全部動画+OSM+航空写真で作る

## 段階B(Opus)への注意

1. **ファイル構成**: `ds_tdl_westernland.py` の docstring・`plan()`・`build_ground()` と同じ作り。`tri/frustum/box/lathe`、`quad/P3/UP`、`polys/text_poly`、`closed_polys` などは import 元を westernland 冒頭に倣う。別タブで `ds_tdl_westernland.py` が未コミットで変更されているので、**そこからの import は避けるか、コミット後に**。岩の関数(`rock_height`、`rock_column`)は流用するなら関数だけ写して色と形を変える
2. **岩山が主役**: 赤い地層の帯+灰ベージュの丸い巨石の二色。ウエスタンランドの尖塔(縦溝)とは別の形にする。頂の切り株の塔は暗い茶の細い束。頂と段の上は苔の緑(丸い刈り込みは禁止、不定形の塊)
3. **寸法**: 魚眼で端が曲がる。山の高さ・滝の幅・道幅はフレームから決めず、OSM 外形(97767482 は x 108 m × y 146 m)と窓 1.2 m・扉 2.1〜2.4 m で割り付ける。高さはすべて推定と docstring に明記
